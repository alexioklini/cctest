**Architecture (build ON the existing shared pipeline, don't fork):** `engine/audio_overview.py`. Reuses `output_gen._gather_sources` (project-scoped retrieval via mempalace_query) + `sidecar_proxy.background_call(purpose="transform")` to write a `HOST_A:/HOST_B:` English dialogue → parse → render each line via Voxtral → concat. Two surfaces, BOTH through the shared `project_outputs` store + `POST .../projects/<name>/generate`: (1) Studio card `kind=audio_overview` → async worker (`run_audio_overview`/`start`) writes .mp3 output row + .md script; (2) agent tool `generate_audio_overview` (audio group, 4-site) → synchronous `generate_to_folder()` writes .mp3+.md to session artifact folder, project-only (refuses outside).

**KEY DECISIONS / GOTCHAS:**
- **MP3 concat = raw byte-concat, NOT ffmpeg.** ffmpeg IS installed (`/opt/homebrew/bin/ffmpeg`) but BROKEN on this host — libx265 link mismatch (needs `.215`, has `.216`); `ffmpeg`/`ffprobe` abort with dyld error. Voxtral returns standard MPEG-3 frames (ID3 header) so `b"".join(segments)` plays as ONE track — validated via macOS `afinfo` (NOT ffprobe, which is also broken). pydub not installed either. If you ever need real concat, fix x265 first.
- **Voxtral TTS wire:** `POST {base}/audio/speech {model,input,voice}` → JSON `{"audio_data":"<base64 mp3>"}` (decode it; some providers send raw). Model `voxtral-mini-tts-latest` @ mistral-direct. Voices ENGLISH-ONLY (10 voices) → audio is English even for German projects, by design. Defaults `gb_oliver_neutral` + `gb_jane_sarcasm`. `_tts_segment` mirrors handlers/translate in-process (worker can't cleanly HTTP its own server).
- **Artifact type + serving:** added `mp3/wav/m4a/ogg`→`audio` to `_ARTIFACT_TYPE_MAP` (brain.py) AND to the artifact-download content-type map (handlers/admin_artifacts.py `_handle_artifact_download`, ~line 1722 — there are TWO identical maps, also one in `_handle_file_download`). Audio serves `Content-Disposition: inline` (not attachment) so the Studio `<audio>` plays it.
- **`update_project_output` whitelists fields** (server_lib/db.py): status/title/path/artifact_id/error/citations/phase/model/tokens_*/cost/duration_s. Reused `citations` as the spoken-line count for audio. Output GET returns the row FLAT (not wrapped in `{output:...}`).
- **Auth for live test:** mint JWT from `config.json.auth.jwt_secret` directly with PyJWT (`{user_id,username,role,exp,iat}`) — a bare `from server_lib import auth; auth.generate_token()` signs with an EMPTY secret (dual-module: no server_config loaded → server rejects it). Admin user_id from auth.db.
- DEFERRED (per plan): interactive "Join" mode, non-English audio (needs multilingual TTS), per-host voice picker in Studio UI (the tool accepts host_a_voice/host_b_voice; Studio uses defaults). `_MAX_LINES=80` caps TTS fan-out.
