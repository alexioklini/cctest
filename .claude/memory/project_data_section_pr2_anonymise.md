**Key design decisions:**
- One Python body, two endpoints — the GUI is just a form that builds the `columns[]` spec; everything after the POST is the same code the agent calls. No "simple" parallel path.
- Index file is a 3-sheet **xlsx** (openpyxl), modelled on the standalone Excel-Anonymisierung tool's mapping workbook — `mapping` (column_id·column_name·normalized_header·original_value·pseudonym), `schema` (which cols, what strategy+opts), `info` (format_version/source_file/salt_present/salt-if-embedded/residual_scan_status/brain_session_id). `embed_salt=false` (default) → hash is irreversible, index records that fact.
- Deferred `fpe` (format-preserving encryption) — needs an FPE lib; the plan OKs deferring it. `noise` shipped but minimal (ε-bounded jitter, not DP).
- The faithful chunked-OOXML in-place rewrite (translate.py's path) for docx/pptx is NOT used here — PR2's xlsx-preserve is openpyxl roundtrip (user's explicit choice). The OOXML-skeleton refactor (`rewrite_office_zip` in `server_lib/translate/document.py`) belongs in PR4 alongside the docx/pptx/PDF format arms — deliberately NOT done in PR2 (don't refactor what this PR doesn't use).
