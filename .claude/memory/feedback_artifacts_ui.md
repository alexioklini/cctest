When building UI features (especially the artifact system), match Claude.ai's look and feel as closely as possible.

**Why:** User wants consistency with Claude.ai's design language — it's the reference implementation.

**How to apply:** Always verify new UI work in Chrome via browser automation tools. For the artifact panel specifically: right-side panel, version selector, type-aware rendering, action buttons — all should feel like Claude.ai.

**Relation to project:** This UI design guidance applies to all web interface features and complements the completed web SPA milestone from project_roadmap.md.
